Demonstrated Service Lifecycles

This video demonstrates the exact user journey and system notifications required under Google Play's VpnService and FOREGROUND_SERVICE_SPECIAL_USE policies:

1. Tunnel Establishment

User taps the central shield button to initiate the encrypted WireGuard / VpnService tunnel with live handshake animation.

2. Foreground Service Active

Android system invokes startForeground() with an ongoing, non-dismissible notification displaying active session stats.

3. Notification Pull-Down

User pulls down the status bar shade to verify the active foreground service notification showing duration, node name, and 1-tap disconnect.

4. Safe Disconnection

User taps disconnect, tearing down the VPN network interface and safely releasing the foreground service without lingering background leaks.
